What MetaClean removes

📷 EXIF camera data

Camera model, lens, ISO, aperture, shutter speed, software version and timestamps.

📍 GPS location

Coordinates embedded by phones that can reveal exactly where a photo was taken.

🗂️ XMP & IPTC

Editing history, author names, keywords, captions and workflow data.

🛡️ C2PA Content Credentials

The provenance record that triggers “Made with AI” labels on Instagram, Facebook and Pinterest.

🤖 AI generator tags

Signatures from DALL·E, Midjourney, Adobe Firefly, Stable Diffusion and other AI tools.

🧩 PNG generation data

Prompts, seed, CFG scale and model hash saved by Automatic1111, ComfyUI and Forge.

🔑 File fingerprint

Invisible shifts to a few pixel values change the file’s unique fingerprint and break reverse-image search.

👤 Device serials

Device serial numbers and other identifiers that fingerprint every photo to one phone.

How it works

01

File stays on your device

Your image is read directly into browser memory. Nothing is sent over the internet at any step.

02

Metadata is detected

MetaClean scans the file and shows you exactly what is embedded — EXIF, GPS, C2PA, AI tags.

03

Image is redrawn clean

The image is redrawn from raw pixels and saved as a fresh file. All embedded metadata is discarded.

04

Clean download

Download the clean copy. The cleaned file is verified — it is scanned again and shows 0 metadata items.

What this tool can’t do: it cannot remove invisible pixel watermarks such as Google’s SynthID — those are baked into the pixels, not the metadata. It cannot change how a platform’s visual AI detection analyses the image itself, and it cannot guarantee a specific result on Instagram, Facebook or any platform. It also cannot undo a label a platform has already applied to a previously uploaded image.

Frequently asked questions

Does my image actually leave my device?

No. Everything happens inside your browser tab. There is no server endpoint that receives your images — the code runs entirely on your device.

Will this remove the “Made with AI” label on Instagram?

It removes the C2PA Content Credentials and AI software tags that trigger the label. However, platforms update their detection without notice and some (like Instagram) can also detect AI content visually. There is no guarantee, but removing metadata is the correct first step.

Can it remove Google SynthID watermarks?

No. SynthID and similar invisible watermarks are embedded directly into pixel values — they are not metadata. No metadata cleaner can remove them.

Does cleaning reduce image quality?

JPEG images are re-encoded at 92% quality (adjustable up to 100%), which is visually identical to the original in nearly all cases. PNG files are exported without any quality loss. The pixel changes used for fingerprint alteration are a maximum of 2 colour values per pixel — completely imperceptible.

Is this really free? What is the catch?

Completely free, no limits, no account required. There is no catch.

What image formats are supported?

JPG/JPEG, PNG, WebP and HEIC (iPhone photos). HEIC files are converted in your browser before cleaning.
